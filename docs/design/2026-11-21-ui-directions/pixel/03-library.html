03 · Library

2026-11-21 · UI directions · Pixel · sheet 03

Library keeps its contents and its four filters and changes how each control is made. Today's header is a title row with search and plus, a row of pill chips, then a “Recents” label with a grid icon. Here creating a playlist is a floating action button, the grid switch is a toggle in the app bar, the fixed “Recents” label is gone, and the list is three grouped containers: playlists and folders, artists, albums.

The fourth filter reads “Songs”. It was “Downloaded”, which described nothing, since every song is a local file.

What was kept

  • The four filters, none selected at first, each clearing on a second tap, and what each one leaves on the page.
  • The contents and their order: Favourites, your playlists, folders, the 40 most recently played artists, every album. Artists and albums most recently played first, then by name.
  • A list view and a three-column grid view, with artist tiles centred. No grid in the song list.
  • The shortcut to the Search tab. It does not filter this screen, as today.
  • Create playlist: a name dialog whose field has focus, a confirm that is disabled while the field is blank, and the new playlist opening straight away.
  • The song list: 127 songs, the sort cycling “Title”, “Artist”, “Recently added”, “Shuffle all songs” with the context “All songs”, and a tap playing the whole list from that row.

Open questions

  • An FAB above a mini player above a navigation bar. It is Material's way to create and it frees the title row, but it is a third floating layer at the bottom. The alternative is a “New playlist” row at the head of the first group, which is how the playlist picker already offers it.
  • The FAB is hidden under three of the four filters. Today's plus is always there. Hiding it keeps it off the song rows' menus and ties it to the lists that hold playlists. Clearing the filter brings it back.
  • Nothing on screen says “Recents” any more. The label was not a control. If the order needs naming, the group labels can say it: “Artists, most recent first”.
  • The sort menu. The arrow half of the split button is a second way to reach the same three sorts. If cycling is enough, the control becomes a plain tonal button and the arrow goes.
  • “Playlist, 12 songs” against “Folder, 46 songs”. Both sit in one group with the same mosaic shape, so the word still does the telling. A small folder glyph on the mosaic would be the other way.
  • Song counts on artists. Today an artist row says only “Artist”. The count is new on this screen; the artist page already shows it.
