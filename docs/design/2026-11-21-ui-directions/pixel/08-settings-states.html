08 · Settings and the states around the app

2026-11-21 · UI directions · Pixel · sheet 08

Settings is rebuilt on the pattern of Android 16's Settings app: sections are grouped containers, rows lead with an icon, and a control sits where its explanation is. The states around the app (asking for access, scanning, an empty library, an item that has gone) are drawn with the same shapes and the same single-action layout.

Every label and status string in section 2.15 and every message in section 2.18 for these screens is here.

What was kept

  • The four sections and their order: “Appearance”, “Lyrics”, “Song radio”, “About”.
  • “Match phone”, “Dark”, “Light”, applied at once. “Dark” is the default.
  • Every Lyrics string: the saved count, “Saved lyrics work offline.”, the lrclib.net note, “Download lyrics for all songs”, “Checked {done} of {total}, found {found}”, and both failure messages.
  • Every Song radio string: “Autoplay” and its description, the on-device note, “Analysing songs: {done} of {total}”, “All {total} songs analysed.”, “{done} of {total} songs analysed. The rest continue next time the phone charges.”, “Analyse now without a charger”. The progress line is always visible; the button shows only when analysis is idle and songs remain.
  • The About sentence with the song count.
  • The mini player and navigation bar on Settings.
  • The permission screen's headline, both bodies and both buttons. The mark is at 72dp.
  • Loading with no text. The empty-library and “is gone” titles and bodies, and the navigation bar on the empty library.

Motion

  • Title. “Settings” scales from 36 to 22 and moves into the bar as the page scrolls; the bar's colour changes on the default effects spring.
  • Theme. The pressed segment widens and its neighbours give way (fast spatial), the check fades in, and the scheme cross-fades on the slow effects spring.
  • Progress. The analysis wave travels at one wavelength a second and flattens when the job stops. The lyrics line grows without a wave.
  • Loading. One shape turning while it morphs through the set, for the seconds a scan takes.
  • Permission refused. Coming back from the prompt, the note's shape fades to grey and its glyph changes; nothing else on the screen moves.

Open questions

  • “Theme” is a new label, added so the Appearance cell has a row like the others. Without it the group holds the button group alone.
  • “Back” on a missing item is a new button that does what the bar's arrow does. It is there so the state has an action in reach of the thumb. It can go.
  • The empty library has no action. A button to open a file manager or to scan again would be new behaviour, so none is drawn.
  • Empty-state shapes. This sheet and sheet 06 use a four-lobed clover for “nothing here yet” and an arch for the permission picture, both defined in the sheet. The kit's empty state is a rounded square. If the clover stays, it belongs in the kit so Search and the collection screens use it too.
  • The icon circles are all secondaryContainer. The phone's Settings gives each section its own colour. One role keeps this page inside the wallpaper scheme; a colour per section would need three more container roles.
